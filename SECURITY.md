# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in mimic-data, please report it
privately by emailing **zulfazlilsm@gmail.com**.

**Please do not report security vulnerabilities through public GitHub issues.**

We will acknowledge receipt within 48 hours and aim to send an initial response
within 5 business days, including a timeline for a fix and disclosure.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x      | :white_check_mark:  |

## Process

1. You send a detailed report to the email above
2. We confirm receipt and begin investigating
3. We develop and test a fix
4. We release the fix and notify you

We appreciate your help keeping mimic-data and its users secure.
